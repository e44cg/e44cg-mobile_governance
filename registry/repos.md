## How to add a repo

When creating a new `e44cg-mobile-*` repo:

1. Add an entry to the Active Repos table above.
2. Copy templates from `templates/` into the new repo.
3. Adapt the CLAUDE.md template for the repo's specific purpose.
4. Commit and push both the new repo and this registry update.
