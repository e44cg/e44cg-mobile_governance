# Mobile Use Cases — Planning Document

Working document for defining what `e44cg-mobile-*` repos to create and why. Use this during mobile sessions to brainstorm, refine, and prioritize.

---

## Questions to explore

- What kinds of work do I want Claude to do while I'm away from my computer?
- What output formats are most useful to review when I sit down at the desktop?
- Are there recurring tasks that could run on a schedule?
- What's the right level of autonomy for each use case?
- Should some repos be PO-adjacent (planning for client work) vs. purely personal?

## Candidate use cases

Use this section to sketch out potential mobile repos. For each, describe:
- **Name:** `e44cg-mobile-[purpose]`
- **What it does:** One sentence.
- **Output type:** What files does it produce? (research notes, workplans, to-do lists, prompts, etc.)
- **How often:** One-time setup, or recurring use?
- **Transfer target:** Where does the output go? (e44cg desktop, PO, or stays here)

### Example format

**Name:** `e44cg-mobile-research`
**What it does:** Produces research summaries on topics Emilio requests.
**Output type:** Markdown files with structured analysis.
**How often:** As needed.
**Transfer target:** e44cg desktop or PO depending on topic.
